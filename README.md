# SNS Camp Frontend

## 概要

SNS Camp は、投稿・フォロー・いいね機能を備えたシンプルな SNS アプリケーションです。本リポジトリはそのフロントエンドで、Next.js で実装されています。

| 技術 | 説明 |
|---|---|
| Next.js 14 (App Router) | フレームワーク |
| React 18 / TypeScript | UI |
| Tailwind CSS | スタイリング |
| react-hot-toast | トースト通知 |

- 緑を基調としたカラースキーム
- レスポンシブデザイン対応
- フォント: Inter（Google Fonts）

### 環境変数

| 変数名 | 説明 | デフォルト値 |
|---|---|---|
| NEXT_PUBLIC_API_URL | APIのエンドポイントURL | http://localhost:8080/api/v1 |

---

## 起動方法

以下のコマンドで起動します。

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` にアクセスして動作を確認します。

環境変数 `NEXT_PUBLIC_API_URL` に接続先のAPIのURLを設定してください（未設定の場合は `http://localhost:8080/api/v1` に接続します）。

## 動作確認

デプロイ後、以下の手順でアプリケーションが正常に動作していることを確認できます。

`<your-host>` は環境に合わせて読み替えてください。
- ローカル環境: `localhost:3000`
- AWS 環境: ALB や ECS に設定したドメイン、または Amplify のドメイン

### 1. ログイン画面の表示

ブラウザで `http://<your-host>` にアクセスし、ログイン画面が表示されることを確認します。

### 2. ユーザ登録

「アカウントをお持ちでない方はこちら」をクリックし、以下を入力して登録します。

- ユーザ名: 任意（英数字3〜20文字）
- メールアドレス: 任意
- パスワード: 8文字以上
- 表示名: 任意

登録成功後、タイムライン画面に遷移すれば正常です。

### 3. 投稿

タイムライン画面のテキストエリアに文章を入力し、「投稿する」をクリックします。投稿がタイムラインに表示されれば正常です。

### 4. 投稿の編集・削除

自分の投稿の「編集」リンクから編集画面に遷移し、内容を変更して「更新する」をクリックします。また、「削除」ボタンで投稿を削除できることを確認します。

### 5. ユーザプロフィール・フォロー

ヘッダーの `@ユーザ名` をクリックし、プロフィール画面が表示されることを確認します。他のユーザがいる場合は、フォロー/フォロー解除が動作することを確認します。

### SCR-004 タイムライン画面

パス: `/timeline`

#### ヘッダー

| 要素 | 種類 | 説明 |
|---|---|---|
| アプリ名 | リンク | "SNS Camp" → `/timeline` |

| 残り文字数 | テキスト | "残り {n} 文字"（20文字未満で赤色表示） |

| 要素 | 種類 | 説明 |
|---|---|---|
| 全投稿ボタン | トグルボタン | 全ユーザの投稿を表示 |

| 要素 | 説明 |
|---|---|

| 削除ボタン | 本人の投稿のみ表示、確認ダイアログあり |

#### 空状態

- 全投稿フィルター: "投稿がありません"

## 共通仕様

### 通知

- 成功・エラーメッセージは画面右上にトースト通知（react-hot-toast）で表示
- 削除操作はブラウザ標準の確認ダイアログで確認

### 認証

- JWT トークンを localStorage に保存
- 認証が必要な画面にアクセスした際、未認証であれば `/login` へリダイレクト
- APIリクエスト時に `Authorization: Bearer {token}` ヘッダーを付与

### ローディング

- データ取得中はスピナーアニメーションを表示
- ボタン送信中はテキスト変更 + 非活性化（opacity-50）
